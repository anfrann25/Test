Cross-Platform Command Reference

◷ 1 min read⌘ Phone, tablet and PC
Device supportBrowser lessons work on phone and PC. Practical commands include Windows, Linux and Termux routes.Choose setup →

Use this table when a lesson shows a command that differs between Windows, Linux and Termux.

TaskWindows PowerShellLinux / WSLTermux

Deletion commands are permanent

Check the current directory and target path before using rm or Remove-Item. Do not paste commands you do not understand.

Common keyboard shortcuts

  • Ctrl + C: stop a running terminal process.
  • Tab: complete a filename or command where supported.
  • ↑ / ↓: browse command history.
  • Ctrl + L: clear many terminal screens.
