Android and Termux Setup

1 min readWindows · Linux · Termux

Android learners can read the complete academy in a normal browser and use Termux for local shell and Python practice. The website never tries to act as a terminal.

1. Prepare Termux

termux-setup-storage
pkg update
pkg upgrade
pkg install python git curl wget nano unzip

2. Start the local academy program

cd ~/storage/downloads/hackthebasics.gr
chmod +x run-academy.sh
./run-academy.sh

Or use python academy.py. The program detects Termux and saves progress inside your Android Termux home directory.

3. Open the educational website locally

python academy.py serve

Open the local address shown by the program in your Android browser. The website remains educational; commands still run in the separate Termux session.

4. Verify

python --version
git --version
uname -m
pwd
ARM compatibility

Most Android devices use ARM. The included x86-64 compiled Linux binaries will not normally run directly in Termux. Use Python challenges, portable shell tasks and theory on Android; complete x86-64-only binaries on WSL or compatible Linux.

Recommended Termux route

  1. Study a lesson in the browser.
  2. Switch to Termux.
  3. Run the shown portable command or Python program.
  4. Record completion with python academy.py complete LESSON_ID or through the interactive menu.
