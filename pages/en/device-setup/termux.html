Android and Termux Setup

◷ 1 min read⌘ Phone, tablet and PC
Device supportBrowser lessons work on phone and PC. Practical commands include Windows, Linux and Termux routes.Choose setup →

Android learners can read every lesson in the browser and use Termux for shell and Python practice. Install Termux only from an official, currently maintained distribution source linked by the Termux project.

1. Prepare storage access

termux-setup-storage

Android will ask for file access. Grant it only when you want Termux to work with shared storage.

2. Update Termux

pkg update
pkg upgrade

3. Install course tools

pkg install python git curl wget nano unzip

4. Verify

python --version
git --version
uname -m
pwd
ARM compatibility

Most Android phones use ARM processors. The course’s precompiled x86-64 Linux binaries will not normally run directly. Use the browser command lab, Python challenges and portable shell exercises on Termux; use WSL/Linux x86-64 for those specific binaries.

Run the website locally in Termux

cd ~/storage/downloads/hackthebasics.gr
python serve.py --port 8000

Then open http://127.0.0.1:8000 in your Android browser.
