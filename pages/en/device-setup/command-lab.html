Local Practice Guide

1 min readWindows · Linux · Termux

HackTheBasics keeps a strict separation: the website teaches; your device performs the practical work.

No simulated terminal

Commands shown in lessons are examples to copy into PowerShell, WSL, Linux or Termux. The website does not execute them and cannot access your files.

Choose the correct local terminal

▣

Windows

PowerShell for Windows tasks; WSL for Linux commands and compatible challenge binaries.

🐧

Linux

Your normal terminal for shell, Python and local challenge directories.

⌁

Termux

Portable shell and Python tasks on Android, with ARM compatibility limits.

Run the academy program

run-academy.bat
./run-academy.sh
./run-academy.sh

The local program can list lessons, show device-specific paths, start the educational website, mark lessons complete and display progress. Its data is stored locally under your user profile.

Example practical workflow

  1. Read the Linux files lesson.
  2. Open your device terminal.
  3. Navigate to the relevant labs directory.
  4. Run only the command described in the lesson.
  5. Return to academy.py and record completion.

Important boundaries

  • Use only systems and files you own or are authorized to test.
  • Do not paste commands you do not understand.
  • Use WSL, a virtual machine or a container for Linux-specific or vulnerable labs.
  • Check architecture before running compiled files.
