Linux Setup

1 min readWindows · Linux · Termux

Linux provides the most direct path for shell, Python and the bundled challenge files. The website explains each task; your local terminal performs it.

1. Start the academy program

chmod +x run-academy.sh
./run-academy.sh

Or use python3 academy.py. Progress is saved under your Linux home directory.

2. Install the learning tools

sudo apt update
sudo apt install python3 python3-pip git curl unzip
sudo dnf upgrade --refresh
sudo dnf install python3 python3-pip git curl unzip

3. Verify your device

python3 --version
git --version
uname -m

4. Open local practice files

cd labs/linux/linux_challenges
ls -la

Python exercises are in labs/python/python_challenges. The command reference explains equivalent tasks across platforms.

Use isolation

Run unfamiliar binaries and deliberately vulnerable software in a disposable virtual machine or container. Do not modify a work or school system without authorization.

Checklist

  • python3 academy.py status runs.
  • Your terminal can access the project folder.
  • uname -m confirms the architecture.
  • You use isolation for risky or vulnerable software.
