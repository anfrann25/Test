Linux Setup

◷ 1 min read⌘ Phone, tablet and PC
Device supportBrowser lessons work on phone and PC. Practical commands include Windows, Linux and Termux routes.Choose setup →

Linux provides the most direct route for the shell, Python and local challenge files. Ubuntu, Debian, Linux Mint, Fedora and similar desktop distributions are suitable.

1. Update your packages

sudo apt update
sudo apt upgrade
sudo dnf upgrade --refresh

2. Install the learning tools

sudo apt install python3 python3-pip git curl unzip
sudo dnf install python3 python3-pip git curl unzip

3. Verify

python3 --version
git --version
uname -m
Use isolation for security tools

Run unfamiliar binaries and deliberately vulnerable software in a disposable virtual machine or container. Do not install challenge tooling into a work or school system without permission.

Optional tools

VirtualBox, GNOME Boxes or Docker can help isolate exercises, but they are not required for the theory or Python lessons.
