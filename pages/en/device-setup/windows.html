Windows Setup

1 min readWindows · Linux · Termux

The website is your textbook. PowerShell, Python and WSL are where the practical work runs. Nothing on the lesson page executes commands for you.

1. Extract the project

Place the complete project in a folder you control, such as Documents\HackTheBasics. Keep the academy.py, labs, tools and website files together.

2. Start the local academy program

run-academy.bat

If the launcher does not open, use PowerShell:

py academy.py

The program detects Windows, lists lessons, shows local lab paths and saves progress in your Windows user profile.

3. Install Python

py --version
python --version

Use a current Python 3 release.

4. Add WSL for Linux exercises

Open PowerShell as Administrator:

wsl --install

Restart if requested, then create a Linux username and password. Inside WSL:

pwd
ls -la
python3 --version

Which terminal should you use?

  • PowerShell: Windows commands and Python.
  • WSL: Linux commands, shell scripts and compatible Linux labs.
  • Virtual machine: isolated security tools or deliberately vulnerable systems.
Run practical files locally

Only run challenge binaries and scripts you obtained with this course, and prefer WSL or a disposable virtual machine for Linux-specific exercises.

Checklist

  • The academy website opens in your browser.
  • py academy.py status runs.
  • PowerShell opens normally.
  • Python reports a version.
  • WSL works for Linux-only lessons.
