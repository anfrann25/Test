Choose Your Learning Device

1 min readWindows · Linux · Termux

HackTheBasics is an educational academy. The website explains concepts, shows commands and prepares you for practical work. It does not execute a terminal, run challenge files or store practical progress.

How practical work is handled

Open the terminal that belongs to your device, run the included local programs there, and use academy.py to store progress in your own user profile.

▣

Windows

Use PowerShell and Python. Add WSL when a lesson specifically needs Linux commands or Linux challenge files.

Open Windows setup → 🐧

Linux

Use the native shell, Python, local challenge directories and optional isolated virtual machines.

Open Linux setup → ⌁

Android + Termux

Use Termux for portable shell and Python exercises. ARM limitations are clearly identified.

Open Termux setup →

The local academy workflow

  1. Read the lesson in the website.
  2. Open PowerShell, WSL, a Linux terminal or Termux.
  3. Run the command or program locally on your device.
  4. Use the terminal academy program to record completion.
  5. Return to the website for the next explanation.

Start the academy program

run-academy.bat

Or run py academy.py from PowerShell.

chmod +x run-academy.sh
./run-academy.sh
chmod +x run-academy.sh
./run-academy.sh
Architecture compatibility

The bundled compiled Linux challenge binaries target x86-64. Most Android phones use ARM, so those specific binaries must be completed on compatible Linux or WSL. Python and portable shell exercises work in Termux.
