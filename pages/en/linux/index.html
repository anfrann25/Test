Linux Fundamentals

1 min readWindows · Linux · Termux

Linux powers many servers, security appliances, cloud workloads and cybersecurity tools. Learning the shell helps you understand how systems store information, start programs and enforce permissions.

Filesystem structure

/
├── home   user data
├── etc    system configuration
├── var    logs and changing service data
├── usr    applications and shared resources
└── tmp    temporary files

Navigation

pwd
ls -la
cd /path/to/folder

pwd displays the current directory. ls -la includes details and hidden entries. cd changes location.

File operations

touch notes.txt
mkdir lab
cat notes.txt
cp source.txt copy.txt
mv old.txt new.txt
rm file.txt

Deletion is normally immediate, so confirm paths before using rm, especially with recursive or privileged options.

Searching

find ~/lab -name 'flag.txt'
grep -Rni 'error' ~/lab

find locates filesystem objects, while grep searches text.

Permissions

Linux permissions control reading, writing and execution for owners, groups and others.

chmod +x script.sh
./script.sh

Avoid running unknown scripts or binaries as root. Use the included challenges inside Docker or a disposable VM.
