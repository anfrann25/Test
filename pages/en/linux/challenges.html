Linux Challenges

1 min readWindows · Linux · Termux

The included Linux lab contains local Capture The Flag exercises. Each level asks you to inspect files, search data, understand permissions or interact with a small program to recover a flag.

Safest setup

Use Docker or a disposable Linux virtual machine. Some original setup files create a training user and install commands under /usr/local/bin, so avoid installing them directly on a primary workstation.

Docker example

From the project root:

sudo docker build -f labs/linux/Dockerfile -t hackthebasics-linux .
sudo docker run --rm -it hackthebasics-linux

CLI workflow

The included htb tools support actions similar to:

htb redeem -m linux -l 1 -f YOUR_FLAG
htb score
htb progress

Skills by level

Levels Main ideas
1–2 normal and hidden files
3–5 searching, file types and executables
6–7 encoding, hashing and program input
8–9 archives, hints and filesystem exploration
10 users, authentication and final challenge

Treat challenge flags as learning checkpoints. The goal is to understand the commands you used, not only to obtain the answer.
