Audit Local Privileges

Review accounts and privileged groups on a device you administer.

3 practical hoursWindows · Linux · TermuxLocal files
OBJECTIVE

Review accounts and privileged groups on a device you administer.

TIME PLAN

Prepare 20m · Build 110m · Verify 30m · Document 20m

Working boundary

Work only inside the folder created by academy.py prepare privilege-audit. Use the supplied samples or systems you personally administer.

Prepare the local workspace

For Audit Local Privileges, open a terminal in the project root and run the command for your platform. The local helper creates this lab’s notes, checklist and safe sample files without changing system configuration.

Windowspy academy.py prepare privilege-auditUse PowerShell or WSL according to the lab commands.
Linuxpython3 academy.py prepare privilege-auditUse the native shell and Python 3.
Termuxpython academy.py prepare privilege-auditUse local storage only after granting explicit access.

Practical mission

  1. List local accounts without exporting sensitive identifiers
  2. Map membership in administrative groups
  3. Identify dormant or unnecessary test access
  4. Plan reversible changes and verify the required work still functions
EVIDENCE TO PRODUCE

A redacted privilege map and a least-privilege remediation plan.

Quality gate

The deliverable states a clear scope and date for Audit Local Privileges.
A second learner can reproduce the commands and paths.
Original samples remain unchanged and verifiable.
Limitations are recorded beside the conclusions.

Analyst reflection

Which result from “Plan reversible changes and verify the required work still functions” would need more evidence before it could support an operational decision?

Complete on the device

After validating the evidence, run academy.py complete privilege-audit with your device’s Python launcher: py on Windows, python3 on Linux, or python in Termux. The website stores no progress.
