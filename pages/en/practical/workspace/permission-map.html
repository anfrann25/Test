Map Local Permissions

Read file ownership and access rules without changing system-wide security settings.

2 practical hoursWindows · Linux · TermuxLocal files
OBJECTIVE

Read file ownership and access rules without changing system-wide security settings.

TIME PLAN

Prepare 15m · Build 70m · Verify 20m · Document 15m

Working boundary

Work only inside the folder created by academy.py prepare permission-map. Use the supplied samples or systems you personally administer.

Prepare the local workspace

For Map Local Permissions, open a terminal in the project root and run the command for your platform. The local helper creates this lab’s notes, checklist and safe sample files without changing system configuration.

Windowspy academy.py prepare permission-mapUse PowerShell or WSL according to the lab commands.
Linuxpython3 academy.py prepare permission-mapUse the native shell and Python 3.
Termuxpython academy.py prepare permission-mapUse local storage only after granting explicit access.

Practical mission

  1. Inspect permissions on source, working and evidence folders
  2. Identify where write access is broader than necessary
  3. Apply a safer permission to a disposable test file
  4. Verify the intended user can still complete the task
EVIDENCE TO PRODUCE

A permission matrix for the academy workspace and two justified corrections.

Quality gate

The deliverable states a clear scope and date for Map Local Permissions.
A second learner can reproduce the commands and paths.
Original samples remain unchanged and verifiable.
Limitations are recorded beside the conclusions.

Analyst reflection

Which result from “Verify the intended user can still complete the task” would need more evidence before it could support an operational decision?

Complete on the device

After validating the evidence, run academy.py complete permission-map with your device’s Python launcher: py on Windows, python3 on Linux, or python in Termux. The website stores no progress.
