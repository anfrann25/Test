Capstone: Establish the Baseline

Create a complete, privacy-aware baseline of the supplied fictional workstation.

4 practical hoursWindows · Linux · TermuxLocal files
OBJECTIVE

Create a complete, privacy-aware baseline of the supplied fictional workstation.

TIME PLAN

Prepare 30m · Build 150m · Verify 40m · Document 20m

Working boundary

Work only inside the folder created by academy.py prepare capstone-baseline. Use the supplied samples or systems you personally administer.

Prepare the local workspace

For Capstone: Establish the Baseline, open a terminal in the project root and run the command for your platform. The local helper creates this lab’s notes, checklist and safe sample files without changing system configuration.

Windowspy academy.py prepare capstone-baselineUse PowerShell or WSL according to the lab commands.
Linuxpython3 academy.py prepare capstone-baselineUse the native shell and Python 3.
Termuxpython academy.py prepare capstone-baselineUse local storage only after granting explicit access.

Practical mission

  1. Prepare the capstone workspace and verify source hashes
  2. Collect host, process, service and network summaries
  3. Document normal application behavior from the scenario
  4. Package the baseline with an index and integrity checksum
EVIDENCE TO PRODUCE

A baseline pack containing inventory, hashes, services, network state and assumptions.

Quality gate

Complete on the device

After validating the evidence, run academy.py complete capstone-baseline with your device’s Python launcher: py on Windows, python3 on Linux, or python in Termux. The website stores no progress.
