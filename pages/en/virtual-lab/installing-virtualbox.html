Installing VirtualBox

1 min readWindows · Linux · Termux

VirtualBox is a free desktop hypervisor for Windows, macOS and Linux.

Before installation

  • Confirm that hardware virtualization is enabled in firmware.
  • Download VirtualBox from the official project website.
  • Check that your operating system version is supported.
  • Keep enough free disk space for virtual disks and snapshots.

Installation

On Windows, run the official installer and review network-driver prompts. On macOS, open the signed package and approve required system extensions in Privacy & Security. On Ubuntu or Debian, use the distribution package or the official repository:

sudo apt update
sudo apt install virtualbox

After installation, open VirtualBox and verify that you can create a test VM. Install optional extension components only when you actually require their features, and obtain them from the official source.
