Installing Kali Linux

1 min readWindows · Linux · Termux

Kali Linux is a Debian-based distribution designed for authorized security testing and training. Its tools do not grant permission to test third-party systems.

Create the VM

  1. Download an official Kali installer image or prebuilt VirtualBox image.
  2. Verify the published checksum when possible.
  3. Create a Debian 64-bit VM.
  4. Assign 2–4 GB RAM and a virtual disk of roughly 30 GB or more.
  5. Use NAT or host-only networking according to the lab.

For an installer ISO, choose the graphical installer, create a normal user and select a lightweight desktop such as XFCE. After the first boot, update packages:

sudo apt update
sudo apt full-upgrade

Do not run every task as root. Take a snapshot once the system is updated and working.
