Snapshots

1 min readWindows · Linux · Termux

A snapshot records the state of a virtual machine at a particular point. It can include virtual disk state, configuration and, optionally, running memory.

Why snapshots matter

  • Return to a known-good state after a broken experiment.
  • Repeat exercises from the same starting point.
  • Test updates or tools without rebuilding the VM.
  • Separate clean, configured and challenge-specific states.

Suggested snapshot points

  1. Clean operating-system installation.
  2. Fully updated base system.
  3. Lab tools configured.
  4. Immediately before a high-risk exercise.

Give snapshots descriptive names and dates. Snapshots are not backups: if the host disk fails, snapshots stored on that disk may also be lost. Keep important configuration and notes in a separate backup.
