Ρύθμιση Windows

2 λεπτά ανάγνωσηςWindows · Linux · Termux

Η ιστοσελίδα είναι το βιβλίο σου. PowerShell, Python και WSL είναι τα σημεία όπου τρέχει η πρακτική. Καμία σελίδα μαθήματος δεν εκτελεί εντολές για εσένα.

1. Αποσυμπίεσε το project

Τοποθέτησε ολόκληρο το project σε φάκελο που ελέγχεις, όπως Documents\HackTheBasics. Κράτησε μαζί τα academy.py, labs, tools και τα αρχεία της ιστοσελίδας.

2. Ξεκίνα το τοπικό πρόγραμμα

run-academy.bat

Αν ο launcher δεν ανοίξει, χρησιμοποίησε PowerShell:

py academy.py

Το πρόγραμμα αναγνωρίζει Windows, εμφανίζει μαθήματα και τοπικά paths και αποθηκεύει την πρόοδο στο προφίλ χρήστη Windows.

3. Εγκατάστησε Python

py --version
python --version

4. Πρόσθεσε WSL για Linux ασκήσεις

Άνοιξε PowerShell ως Administrator:

wsl --install

Κάνε restart αν ζητηθεί και δημιούργησε Linux username/password. Μέσα στο WSL:

pwd
ls -la
python3 --version

Ποιο terminal να χρησιμοποιήσεις;

  • PowerShell: Windows commands και Python.
  • WSL: Linux commands, shell scripts και συμβατά Linux labs.
  • Virtual machine: απομονωμένα security tools ή ευάλωτα συστήματα.
Τρέξε τα πρακτικά αρχεία τοπικά

Τρέξε μόνο challenge binaries και scripts που περιλαμβάνονται στο course και προτίμησε WSL ή disposable virtual machine για Linux-specific ασκήσεις.

Checklist

  • Η ιστοσελίδα της ακαδημίας ανοίγει στον browser.
  • Το py academy.py status λειτουργεί.
  • Το PowerShell ανοίγει κανονικά.
  • Η Python εμφανίζει έκδοση.
  • Το WSL λειτουργεί για Linux-only μαθήματα.
