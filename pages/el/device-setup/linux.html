Ρύθμιση Linux

2 λεπτά ανάγνωσηςWindows · Linux · Termux

Το Linux προσφέρει την πιο άμεση διαδρομή για shell, Python και τα συμπεριλαμβανόμενα challenge files. Η ιστοσελίδα εξηγεί κάθε εργασία· το τοπικό terminal την εκτελεί.

1. Ξεκίνα το πρόγραμμα της ακαδημίας

chmod +x run-academy.sh
./run-academy.sh

Ή χρησιμοποίησε python3 academy.py. Η πρόοδος αποθηκεύεται στο Linux home directory.

2. Εγκατάστησε τα εργαλεία

sudo apt update
sudo apt install python3 python3-pip git curl unzip
sudo dnf upgrade --refresh
sudo dnf install python3 python3-pip git curl unzip

3. Έλεγξε τη συσκευή

python3 --version
git --version
uname -m

4. Άνοιξε τα τοπικά αρχεία πρακτικής

cd labs/linux/linux_challenges
ls -la

Οι Python ασκήσεις βρίσκονται στο labs/python/python_challenges.

Χρησιμοποίησε απομόνωση

Τρέξε άγνωστα binaries και σκόπιμα ευάλωτο λογισμικό σε disposable virtual machine ή container. Μην τροποποιείς σύστημα εργασίας ή σχολείου χωρίς εξουσιοδότηση.

Checklist

  • Το python3 academy.py status λειτουργεί.
  • Το terminal έχει πρόσβαση στον φάκελο του project.
  • Το uname -m επιβεβαιώνει την αρχιτεκτονική.
  • Χρησιμοποιείς απομόνωση για επικίνδυνο ή ευάλωτο λογισμικό.
