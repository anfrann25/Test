2 λεπτά ανάγνωσηςWindows · Linux · Termux

Το HackTheBasics διατηρεί καθαρό διαχωρισμό: η ιστοσελίδα διδάσκει· η συσκευή σου εκτελεί την πρακτική.

Χωρίς προσομοιωμένο terminal

Οι εντολές των μαθημάτων είναι παραδείγματα για αντιγραφή σε PowerShell, WSL, Linux ή Termux. Η ιστοσελίδα δεν τις εκτελεί και δεν έχει πρόσβαση στα αρχεία σου.

Επίλεξε το σωστό τοπικό terminal

▣

Windows

PowerShell για Windows εργασίες· WSL για Linux commands και συμβατά challenge binaries.

🐧

Linux

Το κανονικό terminal για shell, Python και τοπικούς challenge φακέλους.

⌁

Termux

Φορητές shell και Python εργασίες στο Android, με περιορισμούς συμβατότητας ARM.

Τρέξε το πρόγραμμα της ακαδημίας

run-academy.bat
./run-academy.sh
./run-academy.sh

Το τοπικό πρόγραμμα εμφανίζει μαθήματα, paths ανά συσκευή, ξεκινά την εκπαιδευτική ιστοσελίδα, σημειώνει ολοκλήρωση και εμφανίζει πρόοδο. Τα δεδομένα αποθηκεύονται τοπικά στο προφίλ χρήστη.

Παράδειγμα πρακτικής ροής

  1. Διάβασε το μάθημα για Linux files.
  2. Άνοιξε το terminal της συσκευής.
  3. Πήγαινε στον σχετικό φάκελο labs.
  4. Τρέξε μόνο την εντολή που περιγράφει το μάθημα.
  5. Επέστρεψε στο academy.py και κατέγραψε την ολοκλήρωση.

Σημαντικά όρια

  • Χρησιμοποίησε μόνο συστήματα και αρχεία που σου ανήκουν ή έχεις άδεια να ελέγξεις.
  • Μην επικολλάς εντολές που δεν κατανοείς.
  • Χρησιμοποίησε WSL, virtual machine ή container για Linux-specific ή ευάλωτα labs.
  • Έλεγξε την αρχιτεκτονική πριν τρέξεις compiled files.
