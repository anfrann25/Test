Ρύθμιση Android και Termux

2 λεπτά ανάγνωσηςWindows · Linux · Termux

Οι χρήστες Android μπορούν να διαβάσουν ολόκληρη την ακαδημία σε κανονικό browser και να χρησιμοποιήσουν Termux για τοπική shell και Python πρακτική. Η ιστοσελίδα δεν προσπαθεί ποτέ να λειτουργήσει ως terminal.

1. Προετοίμασε το Termux

termux-setup-storage
pkg update
pkg upgrade
pkg install python git curl wget nano unzip

2. Ξεκίνα το τοπικό πρόγραμμα

cd ~/storage/downloads/hackthebasics.gr
chmod +x run-academy.sh
./run-academy.sh

Ή χρησιμοποίησε python academy.py. Το πρόγραμμα αναγνωρίζει Termux και αποθηκεύει την πρόοδο στο Android Termux home directory.

3. Άνοιξε την εκπαιδευτική ιστοσελίδα τοπικά

python academy.py serve

Άνοιξε τη local address που εμφανίζει το πρόγραμμα στον Android browser. Η ιστοσελίδα παραμένει εκπαιδευτική· οι εντολές τρέχουν στην ξεχωριστή συνεδρία Termux.

4. Έλεγξε την εγκατάσταση

python --version
git --version
uname -m
pwd
Συμβατότητα ARM

Τα περισσότερα Android χρησιμοποιούν ARM. Τα x86-64 compiled Linux binaries δεν θα τρέξουν κανονικά στο Termux. Χρησιμοποίησε Python challenges, φορητές shell εργασίες και θεωρία στο Android· ολοκλήρωσε x86-64-only binaries σε WSL ή συμβατό Linux.

Προτεινόμενη διαδρομή Termux

  1. Μελέτησε ένα μάθημα στον browser.
  2. Πήγαινε στο Termux.
  3. Τρέξε την φορητή εντολή ή το Python πρόγραμμα.
  4. Κατάγραψε ολοκλήρωση με python academy.py complete LESSON_ID ή από το interactive menu.
