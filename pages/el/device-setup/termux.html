Ρύθμιση Android και Termux

◷ 1 λεπτά ανάγνωσης⌘ Κινητό, tablet και PC
Υποστήριξη συσκευώνΤα browser lessons λειτουργούν σε κινητό και PC. Οι πρακτικές εντολές περιλαμβάνουν Windows, Linux και Termux.Επίλεξε ρύθμιση →

Σε Android μπορείς να διαβάσεις κάθε μάθημα στον browser και να χρησιμοποιήσεις Termux για shell και Python. Εγκατέστησε το Termux μόνο από επίσημη, ενεργά συντηρούμενη πηγή που συνδέεται από το ίδιο το project.

1. Πρόσβαση σε κοινόχρηστο χώρο

termux-setup-storage

Το Android θα ζητήσει άδεια αρχείων. Δώσε την μόνο όταν θέλεις το Termux να χρησιμοποιεί shared storage.

2. Ενημέρωση Termux

pkg update
pkg upgrade

3. Εγκατάσταση εργαλείων

pkg install python git curl wget nano unzip

4. Έλεγχος

python --version
git --version
uname -m
pwd
Συμβατότητα ARM

Τα περισσότερα Android κινητά χρησιμοποιούν ARM. Τα μεταγλωττισμένα x86-64 binaries του course συνήθως δεν τρέχουν απευθείας. Χρησιμοποίησε browser lab, Python challenges και φορητές shell ασκήσεις στο Termux· χρησιμοποίησε WSL/Linux x86-64 για αυτά τα συγκεκριμένα binaries.

Τοπική εκτέλεση website στο Termux

cd ~/storage/downloads/hackthebasics.gr
python serve.py --port 8000

Άνοιξε μετά το http://127.0.0.1:8000 στον Android browser.

  • Επίσημη ιστοσελίδα Termux
  • Επίσημη τεκμηρίωση πακέτων Termux
