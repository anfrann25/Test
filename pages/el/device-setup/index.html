2 λεπτά ανάγνωσηςWindows · Linux · Termux

Το HackTheBasics είναι εκπαιδευτική ακαδημία. Η ιστοσελίδα εξηγεί έννοιες, παρουσιάζει εντολές και σε προετοιμάζει για την πρακτική. Δεν εκτελεί terminal, δεν τρέχει challenge files και δεν αποθηκεύει την πρακτική πρόοδο.

Πώς γίνεται η πρακτική

Άνοιξε το terminal που ανήκει στη συσκευή σου, τρέξε εκεί τα τοπικά προγράμματα και χρησιμοποίησε το academy.py για να αποθηκεύεις την πρόοδο στο δικό σου προφίλ χρήστη.

▣

Windows

Χρησιμοποίησε PowerShell και Python. Πρόσθεσε WSL όταν ένα μάθημα χρειάζεται ειδικά Linux commands ή Linux challenge files.

Άνοιξε τη ρύθμιση Windows → 🐧

Linux

Χρησιμοποίησε το εγγενές shell, Python, τοπικούς φακέλους challenges και προαιρετικές απομονωμένες virtual machines.

Άνοιξε τη ρύθμιση Linux → ⌁

Android + Termux

Χρησιμοποίησε Termux για φορητές shell και Python ασκήσεις. Οι περιορισμοί ARM αναφέρονται καθαρά.

Άνοιξε τη ρύθμιση Termux →

Η τοπική ροή της ακαδημίας

  1. Διάβασε το μάθημα στην ιστοσελίδα.
  2. Άνοιξε PowerShell, WSL, Linux terminal ή Termux.
  3. Τρέξε την εντολή ή το πρόγραμμα τοπικά στη συσκευή σου.
  4. Χρησιμοποίησε το πρόγραμμα της ακαδημίας στο terminal για να καταγράψεις την ολοκλήρωση.
  5. Επέστρεψε στην ιστοσελίδα για την επόμενη εξήγηση.

Εκκίνηση του προγράμματος ακαδημίας

run-academy.bat

Ή τρέξε py local-tools/academy.py από PowerShell.

chmod +x run-academy.sh
./run-academy.sh
chmod +x run-academy.sh
./run-academy.sh
Συμβατότητα αρχιτεκτονικής

Τα συμπεριλαμβανόμενα compiled Linux challenge binaries στοχεύουν x86-64. Τα περισσότερα Android χρησιμοποιούν ARM, επομένως αυτά τα συγκεκριμένα binaries πρέπει να ολοκληρωθούν σε συμβατό Linux ή WSL. Οι Python και φορητές shell ασκήσεις λειτουργούν στο Termux.
