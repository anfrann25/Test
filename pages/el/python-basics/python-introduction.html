Εισαγωγή στην Python

2 λεπτά ανάγνωσηςWindows · Linux · Termux

Η Python είναι μία από τις πιο δημοφιλείς γλώσσες προγραμματισμού στον κόσμο και χρησιμοποιείται ευρέως στον χώρο του Cybersecurity.

Είναι γνωστή για την απλή σύνταξή της, γεγονός που την καθιστά ιδανική για αρχάριους αλλά και για επαγγελματίες που θέλουν να δημιουργήσουν γρήγορα εργαλεία και αυτοματισμούς.

🛡️ Γιατί χρησιμοποιείται στο Cybersecurity;

Η Python μπορεί να χρησιμοποιηθεί σχεδόν σε κάθε τομέα του Cybersecurity.

Μερικές από τις πιο συνηθισμένες χρήσεις είναι:

  • Automation
  • Network Scanning
  • Web Scraping
  • Malware Analysis
  • Digital Forensics
  • Exploit Development
  • Δημιουργία εργαλείων
  • CTF Challenges

Η γνώση της Python δεν είναι υποχρεωτική, όμως αποτελεί ένα από τα σημαντικότερα εργαλεία που μπορεί να έχει ένας επαγγελματίας του χώρου.

💻 Εγκατάσταση της Python

Μπορείς να κατεβάσεις την τελευταία έκδοση της Python από την επίσημη ιστοσελίδα:

https://www.python.org/downloads/

Κατά την εγκατάσταση στα Windows, βεβαιώσου ότι έχεις ενεργοποιήσει την επιλογή:

Add Python to PATH

Αυτό θα σου επιτρέψει να χρησιμοποιείς την Python απευθείας από το Terminal ή το Command Prompt.

Στα περισσότερα Linux distributions η Python είναι ήδη εγκατεστημένη.

✅ Έλεγχος εγκατάστασης

Άνοιξε ένα Terminal και εκτέλεσε:

python --version

ή

python3 --version

Αν όλα έχουν γίνει σωστά, θα εμφανιστεί κάτι παρόμοιο με:

Python 3.x.x

Το πρώτο μας πρόγραμμα

Δημιούργησε ένα νέο αρχείο με όνομα:

hello.py

και γράψε τον παρακάτω κώδικα:

print("Hello HackTheBasics!")

Αποθήκευσε το αρχείο και εκτέλεσέ το:

python hello.py

ή

python3 hello.py

Αν όλα λειτουργούν σωστά, θα εμφανιστεί:

Hello HackTheBasics!

Η συνάρτηση print()

Η print() χρησιμοποιείται για να εμφανίζει πληροφορίες στην οθόνη.

Παραδείγματα:

print("HackTheBasics")
print("Cybersecurity")
print(2025)

Έξοδος:

HackTheBasics
Cybersecurity
2025

Μπορούμε επίσης να εμφανίσουμε πολλές πληροφορίες μαζί:

target = "192.168.1.10"

print("Target:", target)

Έξοδος:

Target: 192.168.1.10

Τι μάθαμε;

Σε αυτό το κεφάλαιο μάθαμε:

  • Τι είναι η Python.
  • Γιατί χρησιμοποιείται στο Cybersecurity.
  • Πώς να την εγκαταστήσουμε.
  • Πώς να ελέγξουμε ότι λειτουργεί σωστά.
  • Πώς να δημιουργήσουμε και να εκτελέσουμε το πρώτο μας πρόγραμμα.
  • Πώς χρησιμοποιείται η print().

Επόμενο κεφάλαιο

Στο επόμενο μάθημα θα γνωρίσουμε τις Variables και τους Data Types, δηλαδή τον τρόπο με τον οποίο η Python αποθηκεύει και διαχειρίζεται δεδομένα.
