Συνθήκες και Επαναλήψεις

◷ 2 λεπτά ανάγνωσης⌘ Windows, Linux και Termux με Python
Πρακτική στη συσκευήΗ ιστοσελίδα εξηγεί το μάθημα. Οι εντολές και τα προγράμματα τρέχουν μόνο στο δικό σου Windows, Linux ή Termux terminal.Επίλεξε ρύθμιση →

Μέχρι τώρα μάθαμε πώς να αποθηκεύουμε δεδομένα σε μεταβλητές.

Σε αυτό το κεφάλαιο θα μάθουμε πώς ένα πρόγραμμα μπορεί να παίρνει αποφάσεις και να εκτελεί τις ίδιες ενέργειες πολλές φορές χωρίς να γράφουμε τον ίδιο κώδικα ξανά και ξανά.

Conditions (Συνθήκες)

Οι συνθήκες επιτρέπουν στο πρόγραμμα να εκτελεί διαφορετικό κώδικα ανάλογα με μια προϋπόθεση.

Στην Python χρησιμοποιούμε κυρίως:

  • if
  • elif
  • else

Η εντολή if

Η if εκτελεί τον κώδικα μόνο αν η συνθήκη είναι αληθής.

Παράδειγμα:

is_admin = True

if is_admin:
    print("Access Granted")

Έξοδος:

Access Granted

Η εντολή else

Η else εκτελείται όταν η συνθήκη είναι ψευδής.

is_admin = False

if is_admin:
    print("Access Granted")
else:
    print("Access Denied")

Έξοδος:

Access Denied

Η εντολή elif

Η elif χρησιμοποιείται όταν θέλουμε να ελέγξουμε περισσότερες από μία συνθήκες.

port = 443

if port == 22:
    print("SSH")
elif port == 80:
    print("HTTP")
elif port == 443:
    print("HTTPS")
else:
    print("Unknown Service")

Operators

Οι πιο συνηθισμένοι τελεστές σύγκρισης είναι:

Operator Περιγραφή
== Ίσο με
!= Διαφορετικό από
> Μεγαλύτερο από

Παράδειγμα:

port = 80

if port == 80:
    print("HTTP Detected")

Loops

Τα Loops χρησιμοποιούνται όταν θέλουμε να εκτελέσουμε την ίδια ενέργεια πολλές φορές.

Οι δύο βασικοί τύποι είναι:

  • for
  • while

For Loop

Η for χρησιμοποιείται για να διατρέξουμε μια λίστα ή μια ακολουθία δεδομένων.

ports = [22, 80, 443]

for port in ports:
    print(port)

Έξοδος:

22
80
443

Μπορούμε επίσης να διατρέξουμε λίστες με IP Addresses.

targets = [
    "192.168.1.10",
    "192.168.1.20",
    "192.168.1.30"
]

for target in targets:
    print("Scanning", target)

While Loop

Η while εκτελείται όσο μια συνθήκη παραμένει αληθής.

counter = 1

while counter <= 5:
    print(counter)
    counter += 1

Έξοδος:

1
2
3
4
5

Infinite Loops

Αν η συνθήκη μιας while δεν γίνει ποτέ False, τότε το πρόγραμμα θα εκτελείται για πάντα.

Παράδειγμα:

while True:
    print("Running...")

Προσοχή! Αυτό δημιουργεί ένα Infinite Loop και το πρόγραμμα δεν θα σταματήσει μόνο του.

Conditions & Loops στο Cybersecurity

Οι συνθήκες και οι επαναλήψεις χρησιμοποιούνται συνεχώς σε εργαλεία Cybersecurity.

Παραδείγματα:

  • Έλεγχος αν ένας host είναι online.
  • Σάρωση πολλών IP Addresses.
  • Έλεγχος αν μια θύρα είναι ανοιχτή.
  • Ανάγνωση πολλών αρχείων log.
  • Αυτοματοποίηση επαναλαμβανόμενων εργασιών.

🎯 Mini Challenge

Δημιούργησε ένα αρχείο scanner.py.

  1. Δημιούργησε μια λίστα με 5 IP Addresses.
  2. Χρησιμοποίησε ένα for loop για να εμφανίσεις όλες τις IP.
  3. Αν μια IP είναι "192.168.1.100", εμφάνισε:
Target Found!

Για όλες τις υπόλοιπες εμφάνισε:

Scanning...
