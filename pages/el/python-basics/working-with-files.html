Εργασία με Αρχεία

2 λεπτά ανάγνωσηςWindows · Linux · Termux

Ένα από τα μεγαλύτερα πλεονεκτήματα της Python είναι η δυνατότητα να διαβάζει και να δημιουργεί αρχεία.

Στον χώρο του Cybersecurity, τα αρχεία χρησιμοποιούνται συνεχώς. Μπορεί να περιέχουν λίστες με IP Addresses, logs, passwords, αποτελέσματα από scans ή διάφορα configuration files.

Σε αυτό το κεφάλαιο θα μάθουμε πώς μπορούμε να διαβάζουμε και να γράφουμε αρχεία χρησιμοποιώντας την Python.

Άνοιγμα ενός αρχείου

Για να ανοίξουμε ένα αρχείο χρησιμοποιούμε την open().

Παράδειγμα:

file = open("targets.txt", "r")

Η παράμετρος "r" σημαίνει Read Mode, δηλαδή ότι θέλουμε μόνο να διαβάσουμε το αρχείο.

Ανάγνωση ενός αρχείου

Ας υποθέσουμε ότι έχουμε το αρχείο:

targets.txt

192.168.1.10
192.168.1.20
192.168.1.30

Μπορούμε να διαβάσουμε όλο το περιεχόμενο:

file = open("targets.txt", "r")

content = file.read()

print(content)

file.close()

Έξοδος:

192.168.1.10
192.168.1.20
192.168.1.30

Γιατί χρησιμοποιούμε το close();

Όταν τελειώσουμε με ένα αρχείο, είναι καλή πρακτική να το κλείνουμε.

file.close()

Έτσι απελευθερώνονται οι πόροι που χρησιμοποιεί το πρόγραμμα.

Ο καλύτερος τρόπος (with)

Η Python προσφέρει έναν ασφαλέστερο τρόπο διαχείρισης αρχείων.

with open("targets.txt", "r") as file:
    content = file.read()

print(content)

Με το with, το αρχείο κλείνει αυτόματα όταν ολοκληρωθεί η ανάγνωση.

Αυτός είναι και ο τρόπος που χρησιμοποιείται πιο συχνά.

Ανάγνωση γραμμή προς γραμμή

Πολλές φορές δεν θέλουμε να διαβάσουμε όλο το αρχείο μαζί.

Θέλουμε να επεξεργαστούμε κάθε γραμμή ξεχωριστά.

with open("targets.txt", "r") as file:

    for line in file:
        print(line.strip())

Η strip() αφαιρεί τα κενά και τον χαρακτήρα αλλαγής γραμμής (\n).

Έξοδος:

192.168.1.10
192.168.1.20
192.168.1.30

Δημιουργία αρχείου

Μπορούμε επίσης να δημιουργήσουμε ένα νέο αρχείο.

with open("results.txt", "w") as file:
    file.write("Scan Started")

Η παράμετρος "w" σημαίνει Write Mode.

Αν το αρχείο δεν υπάρχει, θα δημιουργηθεί αυτόματα.

Αν υπάρχει ήδη, το περιεχόμενό του θα αντικατασταθεί.

Προσθήκη σε υπάρχον αρχείο

Αν δεν θέλουμε να διαγράψουμε το υπάρχον περιεχόμενο, χρησιμοποιούμε το "a" (Append Mode).

with open("results.txt", "a") as file:
    file.write("\n192.168.1.10 - Online")

Έτσι προσθέτουμε νέα δεδομένα στο τέλος του αρχείου.

Working with Files στο Cybersecurity

Η διαχείριση αρχείων είναι απαραίτητη σχεδόν σε κάθε εργαλείο Cybersecurity.

Παραδείγματα:

  • Ανάγνωση λίστας IP Addresses.
  • Αποθήκευση αποτελεσμάτων από scans.
  • Ανάλυση αρχείων log.
  • Διαχείριση wordlists.
  • Επεξεργασία configuration files.

🎯 Mini Challenge

Δημιούργησε ένα αρχείο με όνομα:

targets.txt

και πρόσθεσε μέσα:

192.168.1.10
192.168.1.20
192.168.1.30
192.168.1.40

Στη συνέχεια δημιούργησε ένα πρόγραμμα που:

  1. Διαβάζει όλες τις IP Addresses.
  2. Τις εμφανίζει στην οθόνη.
  3. Δημιουργεί ένα νέο αρχείο results.txt.
  4. Αποθηκεύει μέσα όλες τις IP Addresses.

Τι μάθαμε;

Σε αυτό το κεφάλαιο μάθαμε:

  • Πώς ανοίγουμε αρχεία.
  • Πώς διαβάζουμε το περιεχόμενό τους.
  • Πώς δημιουργούμε νέα αρχεία.
  • Πώς προσθέτουμε δεδομένα σε υπάρχοντα αρχεία.
  • Γιατί χρησιμοποιούμε το with open().
