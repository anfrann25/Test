2 λεπτά ανάγνωσηςWindows · Linux · Termux

Χρησιμοποίησε τον πίνακα όταν μια εντολή διαφέρει ανάμεσα σε Windows, Linux και Termux.

Οι εντολές διαγραφής είναι μόνιμες

Έλεγξε τον τρέχοντα φάκελο και το target path πριν από rm ή Remove-Item. Μην επικολλάς εντολές που δεν κατανοείς.

Συνηθισμένα shortcuts

  • Ctrl + C: διακοπή διεργασίας terminal.
  • Tab: συμπλήρωση filename ή command όπου υποστηρίζεται.
  • ↑ / ↓: ιστορικό εντολών.
  • Ctrl + L: καθαρισμός πολλών terminal screens.
