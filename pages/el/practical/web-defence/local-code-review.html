ΣΤΟΧΟΣ

Διάβασε σκόπιμα απλό τοπικό handler και βρες αμυντικές βελτιώσεις.

ΧΡΟΝΙΚΟ ΠΛΑΝΟ

Προετοιμασία 20m · Εκτέλεση 110m · Έλεγχος 30m · Τεκμηρίωση 20m

Όριο εργασίας

Δούλεψε μόνο στον φάκελο που δημιουργεί το academy.py prepare local-code-review. Χρησιμοποίησε αποκλειστικά τα δοσμένα δείγματα ή συστήματα που διαχειρίζεσαι.

Προετοίμασε τον τοπικό χώρο

Για το Έλεγχος Τοπικού Web Handler, άνοιξε terminal στον ριζικό φάκελο του project και τρέξε την εντολή της πλατφόρμας σου. Το τοπικό helper δημιουργεί τις σημειώσεις, το checklist και τα ασφαλή sample files αυτού του lab χωρίς αλλαγές στο σύστημα.

Windowspy academy.py prepare local-code-reviewPowerShell ή WSL ανάλογα με τις εντολές του lab.
Linuxpython3 academy.py prepare local-code-reviewΧρησιμοποίησε εγγενές shell και Python 3.
Termuxpython academy.py prepare local-code-reviewΧρησιμοποίησε τοπικό storage μόνο με ρητή πρόσβαση.

Πρακτική αποστολή

  1. Ιχνηλάτησε δεδομένα από input σε storage ή output
  2. Βρες ένα ελλιπές validation και ένα unsafe error path
  3. Εφάρμοσε τη μικρότερη σαφή διόρθωση
  4. Γράψε tests που αποτυγχάνουν πριν και περνούν μετά
ΠΑΡΑΔΟΤΕΟ

Σημείωση code review με evidence, impact, fix και verification για κάθε θέμα.

Έλεγχος ποιότητας

Το παραδοτέο αναφέρει σαφώς scope και ημερομηνία για το Έλεγχος Τοπικού Web Handler.
Οι εντολές και τα paths μπορούν να επαναληφθούν από δεύτερο άτομο.
Τα πρωτότυπα samples παραμένουν αμετάβλητα και επαληθεύσιμα.
Οι περιορισμοί καταγράφονται δίπλα στα συμπεράσματα.

Αναστοχασμός

Ποιο αποτέλεσμα από το βήμα «Γράψε tests που αποτυγχάνουν πριν και περνούν μετά» θα χρειαζόταν επιπλέον evidence πριν γίνει επιχειρησιακή απόφαση;

Ολοκλήρωση στη συσκευή

Μετά τον έλεγχο των τεκμηρίων, τρέξε academy.py complete local-code-review με τον Python launcher της συσκευής: py στα Windows, python3 στο Linux ή python στο Termux. Η ιστοσελίδα δεν αποθηκεύει πρόοδο.
