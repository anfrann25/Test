Ανάλυση Δομημένων Logs

Μετέτρεψε μικτό sample log σε κανονικοποιημένες εγγραφές και χρήσιμες μετρήσεις.

3 ώρες πρακτικήςWindows · Linux · TermuxΤοπικά αρχεία
ΣΤΟΧΟΣ

Μετέτρεψε μικτό sample log σε κανονικοποιημένες εγγραφές και χρήσιμες μετρήσεις.

ΧΡΟΝΙΚΟ ΠΛΑΝΟ

Προετοιμασία 20m · Εκτέλεση 110m · Έλεγχος 30m · Τεκμηρίωση 20m

Όριο εργασίας

Δούλεψε μόνο στον φάκελο που δημιουργεί το academy.py prepare log-parser. Χρησιμοποίησε αποκλειστικά τα δοσμένα δείγματα ή συστήματα που διαχειρίζεσαι.

Προετοίμασε τον τοπικό χώρο

Για το Ανάλυση Δομημένων Logs, άνοιξε terminal στον ριζικό φάκελο του project και τρέξε την εντολή της πλατφόρμας σου. Το τοπικό helper δημιουργεί τις σημειώσεις, το checklist και τα ασφαλή sample files αυτού του lab χωρίς αλλαγές στο σύστημα.

Windowspy academy.py prepare log-parserPowerShell ή WSL ανάλογα με τις εντολές του lab.
Linuxpython3 academy.py prepare log-parserΧρησιμοποίησε εγγενές shell και Python 3.
Termuxpython academy.py prepare log-parserΧρησιμοποίησε τοπικό storage μόνο με ρητή πρόσβαση.

Πρακτική αποστολή

  1. Αναγνώρισε έγκυρες εγγραφές και κράτησε αριθμούς γραμμών
  2. Κανονικοποίησε timestamps σε μία ρητή ζώνη ώρας
  3. Μέτρησε τύπους συμβάντων χωρίς απόρριψη κακοσχηματισμένων γραμμών
  4. Γράψε τις απορριφθείσες εγγραφές σε ξεχωριστό review file
ΠΑΡΑΔΟΤΕΟ

Parser, καθαρό CSV ή JSON output και περίληψη σφαλμάτων.

Έλεγχος ποιότητας

Το παραδοτέο αναφέρει σαφώς scope και ημερομηνία για το Ανάλυση Δομημένων Logs.
Οι εντολές και τα paths μπορούν να επαναληφθούν από δεύτερο άτομο.
Τα πρωτότυπα samples παραμένουν αμετάβλητα και επαληθεύσιμα.
Οι περιορισμοί καταγράφονται δίπλα στα συμπεράσματα.

Αναστοχασμός

Ποιο αποτέλεσμα από το βήμα «Γράψε τις απορριφθείσες εγγραφές σε ξεχωριστό review file» θα χρειαζόταν επιπλέον evidence πριν γίνει επιχειρησιακή απόφαση;

Ολοκλήρωση στη συσκευή

Μετά τον έλεγχο των τεκμηρίων, τρέξε academy.py complete log-parser με τον Python launcher της συσκευής: py στα Windows, python3 στο Linux ή python στο Termux. Η ιστοσελίδα δεν αποθηκεύει πρόοδο.
