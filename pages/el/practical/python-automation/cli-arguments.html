Δημιουργία Αξιόπιστου CLI

Γράψε εργαλείο Python γραμμής εντολών που ελέγχει input και αποτυγχάνει καθαρά.

3 ώρες πρακτικήςWindows · Linux · TermuxΤοπικά αρχεία
ΣΤΟΧΟΣ

Γράψε εργαλείο Python γραμμής εντολών που ελέγχει input και αποτυγχάνει καθαρά.

ΧΡΟΝΙΚΟ ΠΛΑΝΟ

Προετοιμασία 20m · Εκτέλεση 110m · Έλεγχος 30m · Τεκμηρίωση 20m

Όριο εργασίας

Δούλεψε μόνο στον φάκελο που δημιουργεί το academy.py prepare cli-arguments. Χρησιμοποίησε αποκλειστικά τα δοσμένα δείγματα ή συστήματα που διαχειρίζεσαι.

Προετοίμασε τον τοπικό χώρο

Για το Δημιουργία Αξιόπιστου CLI, άνοιξε terminal στον ριζικό φάκελο του project και τρέξε την εντολή της πλατφόρμας σου. Το τοπικό helper δημιουργεί τις σημειώσεις, το checklist και τα ασφαλή sample files αυτού του lab χωρίς αλλαγές στο σύστημα.

Windowspy academy.py prepare cli-argumentsPowerShell ή WSL ανάλογα με τις εντολές του lab.
Linuxpython3 academy.py prepare cli-argumentsΧρησιμοποίησε εγγενές shell και Python 3.
Termuxpython academy.py prepare cli-argumentsΧρησιμοποίησε τοπικό storage μόνο με ρητή πρόσβαση.

Πρακτική αποστολή

  1. Δέξου input και output paths με argparse
  2. Απόρριψε ανύπαρκτες ή μη ασφαλείς διαδρομές πριν την επεξεργασία
  3. Επέστρεψε διαφορετικά exit codes για usage και data errors
  4. Δοκίμασε help, επιτυχία και τέσσερις συνθήκες αποτυχίας
ΠΑΡΑΔΟΤΕΟ

Τεκμηριωμένο CLI με help, exit codes και έξι test cases.

Έλεγχος ποιότητας

Το παραδοτέο αναφέρει σαφώς scope και ημερομηνία για το Δημιουργία Αξιόπιστου CLI.
Οι εντολές και τα paths μπορούν να επαναληφθούν από δεύτερο άτομο.
Τα πρωτότυπα samples παραμένουν αμετάβλητα και επαληθεύσιμα.
Οι περιορισμοί καταγράφονται δίπλα στα συμπεράσματα.

Αναστοχασμός

Ποιο αποτέλεσμα από το βήμα «Δοκίμασε help, επιτυχία και τέσσερις συνθήκες αποτυχίας» θα χρειαζόταν επιπλέον evidence πριν γίνει επιχειρησιακή απόφαση;

Ολοκλήρωση στη συσκευή

Μετά τον έλεγχο των τεκμηρίων, τρέξε academy.py complete cli-arguments με τον Python launcher της συσκευής: py στα Windows, python3 στο Linux ή python στο Termux. Η ιστοσελίδα δεν αποθηκεύει πρόοδο.
