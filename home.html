LOCAL-FIRST WORKFLOW

The browser teaches. The device does the work.

No simulated terminal and no browser progress database. The included Python companion prepares workspaces and records completion under your own user profile.

Read with context

Understand the goal, safety boundary and expected evidence before running a command.

Prepare locally

Use academy.py to create a clean lab folder with notes and supplied sample data.

Execute and verify

Run native commands or Python, preserve outputs and test the claimed result.

Record the evidence

Complete the local checklist and mark the lab in the device-based progress file.
