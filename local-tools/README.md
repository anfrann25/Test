# Local tools

These optional scripts run the academy locally and track practice progress.

## Linux

```bash
./local-tools/start-site.sh
```

## Termux

```bash
./local-tools/start-termux.sh
```

## Windows

Run `local-tools\start-site.bat` or `local-tools\start-site.ps1`.

The main CLI can also be called directly with `python3 local-tools/academy.py`.
